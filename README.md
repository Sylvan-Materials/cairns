# cairns
compile-time with reflection utilities header only library

## License
MIT

## Usage
```cpp
#include <cairns.h>
```

or
```cpp
#include <cairns/fixed_string.h>
#include <cairns/fixed_accumulator.h>
#include <cairns/fixed_stack.h>
```

## Features
- fixed_string
- fixed_accumulator
- fixed_stack
