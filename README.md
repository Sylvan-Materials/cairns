# cairns
compile-time with reflection utilities header only library

## License
MIT

## Usage
```cpp
#include <cairns.h>
```

or
```cpp
#include <cairns/bit_set.h>
#include <cairns/fixed_accumulator.h>
#include <cairns/fixed_map.h>
#include <cairns/fixed_stack.h>
#include <cairns/fixed_string.h>
#include <dfs.h>
```

## Features
- fixed_string
- fixed_accumulator
- fixed_stack
- fixed_map
- bit_set

- dfs
